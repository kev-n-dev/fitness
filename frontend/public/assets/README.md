# OxiHuman Asset Pack

This directory should contain the OxiHuman core asset pack for the 3D body visualizer.

## Required File

- `oxihuman-core-v1.ohpk` (~2MB) - The core asset pack containing body mesh and morph targets

## Download Instructions

Download the asset pack from the OxiHuman releases:

1. Go to https://github.com/cool-japan/oxihuman/releases
2. Download `oxihuman-core-v1.ohpk` from the latest release
3. Place it in this directory (`frontend/public/assets/`)

Alternatively, if you have the OxiHuman repository cloned:
```bash
cp /path/to/oxihuman/assets/packs/oxihuman-core-v1.ohpk ./
```
